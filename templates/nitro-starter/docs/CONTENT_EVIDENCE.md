# Matriz de contenido y evidencia

Cada afirmación visible debe tener una fuente concreta. Una inferencia no es
evidencia. No uses una fila en estado pendiente dentro de la interfaz.

| Afirmación | Estado | Fuente exacta | Uso permitido |
|---|---|---|---|
| Nombre del producto | PENDIENTE | | |
| Precio | PENDIENTE | | |
| Contenido del kit | PENDIENTE | | |
| Envío y entrega | PENDIENTE | | |
| Garantía | PENDIENTE | | |
| Retracto / devolución | PENDIENTE | | |
| Identidad del vendedor | PENDIENTE | | |

Estados: `CONFIRMADO`, `PENDIENTE`, `PROHIBIDO`, `DEMO FICTICIO`. Este último
solo es válido en modo demo y bloquea publicación.
